# Portfolio — Ange Trésor Djomo

Site personnel : conseiller bancaire agréé AMF, développeur full-stack (KargoJet, KÖLÖ), ancien enseignant.

## Stack

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- `next/font` (Fraunces, Inter, JetBrains Mono) — aucune requête externe
- SEO : `robots.ts`, `sitemap.ts`, `opengraph-image.tsx`, JSON-LD `Person`
- FR/EN togglable côté client (`src/lib/content.ts`)

## Développement

```bash
npm install
npm run dev
```

## Déploiement

Déployé sur Vercel, branché sur ce repo GitHub.
